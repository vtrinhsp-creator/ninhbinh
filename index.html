⚪ Chưa cấu hình Firebase
📖 Hướng dẫn 3 bước tạo Firebase miễn phí & Security Rules:
1. Truy cập console.firebase.google.com → Tạo Project mới → Mở Build > Realtime Database → Bấm Create Database (chọn Singapore).
2. Copy đường dẫn https://...firebaseio.com dán vào ô phía trên và bấm Kiểm tra kết nối Firebase.
3. Chuyển sang tab Rules trong Realtime Database và dán cấu hình database.rules.json sau: 
{
  "rules": {
    "ninhbinh_mien_di_san": {
      ".read": true,
      ".write": true
    }
  }
}
